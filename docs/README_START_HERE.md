# Start Here

Give this entire folder to Claude Code.

Recommended first instruction:

Read `CLAUDE.md` and every specification document in this folder before coding.

Do not implement the entire platform.
Start only with Phase 1 in `DEVELOPMENT_PHASES.md`.

Before writing production code:
1. summarize your understanding of the product
2. propose the Phase 1 folder/module architecture
3. list database migrations to be created
4. list main API endpoints
5. list frontend screens
6. identify any assumptions

Then implement Phase 1.

Do not add features outside the documented scope without explicit instruction.
