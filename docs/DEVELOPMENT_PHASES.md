# Development Phases

## Phase 1 — Foundation + Core CRM
Build first.

### Scope
- project setup
- authentication
- organization model
- roles and permissions
- company management
- contact management
- agent management
- opportunity management
- pipeline stages
- stage history
- tasks / follow-ups
- activity timeline
- dashboard
- in-app notifications
- audit log

### Dashboard minimum
- leads due for follow-up
- overdue tasks
- opportunities with no next action
- active pipeline value
- opportunities by stage
- recent activity

### Phase 1 completion condition
Owner can manage the full lead lifecycle from referral to won/lost without using a separate to-do list.

---

## Phase 2 — Project Handover + Agent Portal

### Scope
- convert won opportunity to project
- PM assignment
- project status
- project handover checklist
- project tasks
- agent login portal
- agent pipeline visibility
- simplified agent-facing stage mapping
- basic agent performance metrics

---

## Phase 3 — AI Assistant + Telegram

### Scope
- AI assistant chat interface
- read-only AI queries first
- opportunity/company summaries
- daily planner
- risk detection
- suggested actions
- confirmation-based write tools
- Telegram notifications
- Telegram daily brief

---

## Phase 4 — Communication Integrations

### Scope
- email integration
- calendar integration
- optional WhatsApp integration
- meeting/communication logging
- AI inbox summarization
- suggested CRM updates

No automatic outreach unless explicitly approved.

## Phase 5 — SaaS Productization

### Scope

- industry templates
